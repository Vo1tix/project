# Задача 1, вариант 27, фокус А

## Тема
История отмен. Есть массив на b элементов.

Реализованы два способа:

1. HalfHistory — при заполнении отбрасывается старая половина истории.
2. OneHistory — при заполнении отбрасывается только одно самое старое действие.

## Запуск тестов
python -m unittest discover -s tests

## Запуск замеров
python benchmark.py

## Теория

HalfHistory: раз в b/2 добавлений копируется b/2 элементов.
Амортизированно O(1), худший случай одной операции O(b).

OneHistory: после заполнения каждая операция копирует b-1 элемент.
Амортизированно O(b), худший случай O(b).

## Память
Обе структуры хранят не больше b действий: O(b).
